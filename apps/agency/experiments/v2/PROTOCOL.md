# Travel classifier V2 · preregistered experiment

Created 21 September 2026 before new final-test generation or scoring.

Goal: beat Jev on travel decision accuracy with positive paired 95% interval for local-minus-Jev accuracy, while achieving macro F1 >=0.85 and accepted-decision error <=5%. Report all measures, confidence intervals, class-wise recall and acceptance coverage; abstaining on everything is not success. Preserve V1 weights, data, reports and app until a validated replacement exists.

Development: broaden independently labeled scenarios across cancellation/refund exclusions, overnight arrival prerequisites, onsite/included swimming facilities and guided-hike inclusions. Include irrelevant sentences, explicit negation, missing information, conflicting statements, package/rate distinctions, dates and untrusted instructions. Reference facts are specified before prose. Validate generated prose against those facts; reject mismatches, retain rejection ledger. Model-assisted checks are not human validation.

Candidates: stronger 3-way NLI encoder, improved ModernBERT adaptation on diverse data, and a small instruction model converted to fixed-label classification if encoders plateau. Candidate and hyperparameter choice uses train/development only. Existing V1 test is now historical diagnostic data and cannot establish fresh improvement.

Calibration: separate data, freeze probability temperature and acceptance threshold before final test. Every model sees the same full document and question/candidate meanings. No oracle segmentation or fields supplied to only one model. Record prompt/serialization, truncation, failures, timing and hardware. No Jev outputs train or tune the local model.

Final: after selecting and freezing one model, generate an independently rendered, newly seeded final corpus using a different rendering procedure/source from training. Fix sampling, labels and hashes before either engine is scored. All cases count; do not discard failures by model outcome. Run both engines once against identical cases. If final evaluation fails, preserve the loss and retire that test from future final-test status; make the next selection without optimizing to those particular errors and create a new test. Report sequential attempts, not only the winner. Replicate an apparent win on another fresh batch before claiming demonstrated superiority.

Public independent suites remain separate generalization checks. Do not claim universal superiority, official TypeSafe benchmark reproduction, or production booking safety from synthetic reference agreement. Cost and latency reported separately from quality. External compute permitted if locally observed throughput justifies it. Existing USD10 conservative Jev experiment budget retained; no unbounded paid jobs.

Development expansion before any V2 freeze/final: 144 additional authored scenarios (48 distinct target clauses, reordered with other travel requirements) cover package/property scope, superseded or unresolved policies, date-specific terms and untrusted quoted instructions. These are development-only synthetic labels, not human annotation. The selected model now uses combined 400 broad-prose + 144 robustness development scenarios. The independent baseline robustness accuracy is 78.47%; the earlier 99.375% simple-dev score must never stand in for this result. No training on robustness-dev verbatim. Stronger training may add separately worded examples of these phenomena; final generation remains subsequent to freeze.

Coverage requirement clarified before model freeze, final generation, or any V2 Jev scoring (21 September 2026, second training pass underway): confidently accepted correct `meets` decisions must recover at least 50% of all reference `meets` decisions, both in calibration and each fresh final round. This operational floor prevents a tiny set of approvals from qualifying the holiday recommender. It is an additional constraint, not a relaxation of macro F1>=.85, false accepts<=5%, or the positive paired interval requirement. It was chosen without any final-test outcomes. Report total acceptance coverage and this reference-meets recall separately.
