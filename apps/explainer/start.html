Your first working check.

Start with the supplied travel model. Training for a new job comes later.

Delivery status: private preparation.

One repository: private during preparation, public when the video goes live. This same repository will hold the source and companion release. Until launch, access is restricted.

Private repository ↗

1. Check the machine

Tested on Apple M5 Max, 128 GB memory, macOS 26.5.2. This is the demonstration host, not a minimum requirement. The supplied vision runtime needs Apple silicon and about 16 GB of model downloads. That download size does not establish RAM requirements. Windows/Linux vision and lower-memory machines have not been validated.

Install Python 3.12, uv, Node 22 or later, npm, Git and GitHub CLI through their official installers. The source kit uses a Python environment separate from the vision runtime. A local model check does not require a paid Jev account; repeating the hosted benchmark does.

2. Get the source and weights

With private-repository access, open a terminal and run:

git clone https://github.com/promptadvisers/away-together.git
cd away-together
gh release download companion-v1 --repo promptadvisers/away-together --pattern Away-Together-Complete.zip --dir downloads
python3 tools/restore_companion.py downloads/Away-Together-Complete.zip

The restore tool verifies every manifest hash and refuses conflicting source files. Use the matching release in a clean folder if it reports a mismatch. Never overwrite your own changes to silence it.

3. Install and start the text app

cd apps/agency
uv sync --frozen
npm --prefix app ci
npm --prefix app run build
cd ../..
python3 tools/first_run.py
python3 tools/first_run.py --start

Leave that terminal open. Open localhost:8765. Run a holiday and inspect its reasons. The first check loads the model; later checks are warmer. Successful setup means a fresh model result, not merely a page loading.

4. Enable images separately

On Apple silicon, open another terminal in the source-kit folder:

cd apps/agency
uv run python scripts/start_vision.py --setup --background

This step downloads the pinned pretrained image model and starts port 8081. No image training runs. Inspect the model’s upstream terms before using it.

5. Open the visual walkthrough

python3 apps/explainer/serve.py

Open localhost:8770. Include the stairs photo and check Maya, then remove it and check again. The demonstrated result changes from decline to review. Missing evidence does not prove a step-free route.

If something fails

What you seeWhat to do
Repository not found / no accessThe repository is private. Obtain the authorized resource link or access; do not treat this as an installation error.
Missing modelRestore the matching companion archive. The Git source alone excludes large weights.
Command not foundInstall the prerequisite named by first_run.py, reopen the terminal, and run the check again.
Address already in useCheck whether your existing service is healthy. Avoid starting a second copy on the same port.
Photo model unavailableCheck Apple silicon, finish the separate download, and start the vision service. Text can be run separately.
Computer asleep or terminal closedWake the machine and restart the relevant service. This kit is a local demo, not always-on hosting.
High memory use or slow first requestStop other model jobs. Minimum memory and your hardware speed are not established by this demo.
